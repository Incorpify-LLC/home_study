# QA, Security, and Pedagogy Audit — 2026-10-30

## Final status

**Verdict:** viable and well-built. The core assessment engine is sound, and every actionable finding from this audit has been resolved, tested, deployed, production-verified, and closed.

This document records a point-in-time review. “Passed” means the stated checks passed on the reviewed release; it is not a claim that the application can never contain a security defect.

## Product and pedagogy review

Home Study is a private family study workspace for Classes VIII, X, and XII. Its chapter workflow is:

1. Understand the concept overview, key ideas, worked example, and study tips.
2. Apply the material through same-topic questions with confidence capture.
3. Submit once for server-side grading.
4. Review corrections and explanations.
5. Revisit the recorded attempt through History and the adaptive plan.

Strengths observed during the audit:

- The learning loop follows explain → model → practice → explained review.
- Confidence capture supports metacognition instead of recording answers alone.
- The interface uses growth-oriented language and treats an initial result as evidence for improvement.
- Sampled Class X Chemistry content was scientifically accurate and aligned with the applicable CISCE syllabus topics.
- Scheduling interleaves subjects within a daily minute budget rather than presenting an unstructured queue.

## Security checks

| Check                                 | Verified result                                                                                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Answer-key exposure before submission | Current-assignment responses omit correct-answer fields.                                                                            |
| Grading authority                     | Grading is server-side; client-supplied score values are not authoritative.                                                         |
| Answer validation                     | Malformed answer payloads are rejected.                                                                                             |
| Feedback timing                       | Correct answers and explanations are disclosed after submission.                                                                    |
| Role and ownership boundaries         | Tested student requests did not expose parent or administrative resources; no IDOR surfaced in the exercised paths.                 |
| Transport and authentication          | The family hostname remains protected by Cloudflare Access; application responses retain the established security controls.         |
| Unknown learning selectors            | Unsupported `/api/learning/*` query parameters now return HTTP 400 rather than being silently ignored.                              |
| Dependency and secret audit           | The final gate found no npm vulnerabilities at the configured moderate threshold, and Gitleaks found no leaks in reachable history. |

## Findings and resolution index

### #1 — Class progress counter stale until reload

- **Outcome:** resolved and closed.
- **Change:** refresh class progress immediately after a successful chapter submission.
- **Implementation:** `7fccbaf`
- **Closure:** `4b4ba59`
- **Production Worker:** `d11fc40b-d8a7-4906-a4c0-b8099133dee6`
- **Issue:** <https://github.com/Incorpify-LLC/home_study/issues/1>

### #2 — “Completed” conflated attempts with mastery

- **Outcome:** resolved and closed.
- **Change:** distinguish attempted chapters from mastered chapters. Mastery requires `possible > 0` and `earned / possible >= 0.8`; a lower-scoring submission is shown as needing another pass.
- **Implementation:** `a4c4a98`
- **Closure:** `2b86f39`
- **Production Worker:** `91ce8e73-1090-4e55-a32a-f092dc3606c1`
- **Issue:** <https://github.com/Incorpify-LLC/home_study/issues/2>

### #3 — Planned-minutes ring used a misleading completion label

- **Outcome:** resolved and closed.
- **Change:** Today’s indicator describes the percentage “of today’s minutes scheduled,” while roadmap progress describes the percentage “of course mastered.”
- **Implementation:** `fae849c`
- **Closure:** `b5deae8`
- **Production Worker:** `d9249d2a-1895-48da-85ff-268b4a0f1322`
- **Issue:** <https://github.com/Incorpify-LLC/home_study/issues/3>

### #4 — Unknown learning query parameters were silently ignored

- **Outcome:** resolved and closed.
- **Change:** reject unsupported `/api/learning/*` query parameters with HTTP 400 and `unknown_query_parameter`; retain the supported subject filter on current/next assignment routes.
- **Implementation:** `2905bd6`
- **Closure:** `827ec0e`
- **Production Worker:** `1041ad4b-f6db-4122-a1d1-cf2d3477cafe`
- **Issue:** <https://github.com/Incorpify-LLC/home_study/issues/4>
